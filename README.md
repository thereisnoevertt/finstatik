# Finstatik
Finstatik представляет собой образовательную платформу, включающую в себя новости, уроки и тесты, нацеленные на увеличение уровня финансовой грамотности пользователя. Проект построен на Python + Fast API + Postgres.

## Основные возможности

**Модульная система обучения** - структурированные модули с уроками

**Интерактивные тесты (квизы)** - проверка знаний с множественным выбором

**Система прогрессии** - монеты, рейтинговые очки, streak

**Лидерборды** - соревнование по рейтингу, монетам и streak

**Магазин** - покупка товаров за внутриигровую валюту

**Система целей** - пользователи могут ставить финансовые цели

**Новостная лента** - актуальные новости финансовой сферы

**JWT аутентификация** - безопасная система авторизации

### Система аутентификации
JWT токены
Проект использует JWT (JSON Web Tokens) для аутентификации:

Access Token: живет 24 часа (1440 минут)
Алгоритм: HS256
Секретный ключ: настраивается в переменных окружения

### Особенности проекта
**Система прогрессии**

Монеты: получаются за прохождение уроков и тестов
Рейтинговые очки: начисляются пропорционально монетам (1 очко за 10 монет)
Streak: подсчитывается ежедневная активность пользователя
Prerequisite система: уроки могут быть заблокированы до прохождения предыдущих

**Лидерборды**

Три типа рейтингов:

- По рейтинговым очкам
- По количеству монет
- По streak (дням подряд)

## API Документация
### Аутентификация
POST /auth/register     # Регистрация пользователя

POST /auth/token        # Получение JWT токена
### Профиль
GET  /profile/me        # Получение профиля текущего пользователя
### Обучение
GET  /modules/                    # Список всех модулей с уроками

GET  /lessons/{lesson_id}         # Получение урока по ID

POST /lessons/{lesson_id}/complete # Завершение обучающего урока
### Тестирование
GET  /quiz/{lesson_id}           # Получение вопросов теста

POST /quiz/{lesson_id}/submit    # Отправка ответов на тест
### Цели
GET  /goals/                     # Список целей пользователя

POST /goals/                     # Создание новой цели

POST /goals/{goal_id}/deposit    # Внесение средств в цель
### Магазин
GET  /store/                     # Список товаров в магазине

POST /store/buy/{item_id}        # Покупка товара
### Лидерборды
GET  /leaderboard/rating         # Лидерборд по рейтингу

GET  /leaderboard/coins          # Лидерборд по монетам  

GET  /leaderboard/streak         # Лидерборд по streak
### Новости
GET  /news/                      # Список новостей

POST /news/                      # Создание новости (admin)
